# מקור נתונים פרטי ל-OpenStreetMap: שלוש דרכים, ומה אני ממליץ

הקטלוג העולמי (`npm run data:world`) נבנה מ-Overpass, שירות שאילתות על מפת OpenStreetMap.
השרתים הציבוריים הם של מתנדבים: עמוסים בשעות היום, מחזירים 504 ו-500, ומגבילים כתובת
שמריצה מאות שאילתות. התוצאה: 3 עד 10 ערים בשעה וכשלים אקראיים.

**תיקון למה שאמרתי קודם:** "שרת פרטי ב-10 דולר לחודש" נכון לאזור אחד (למשל אירופה),
לא לכל העולם. מסד Overpass של כל הכוכב דורש כ-500GB דיסק מהיר, 32GB זיכרון ויומיים-שלושה
של ייבוא, כלומר 60 עד 120 דולר לחודש. לכן יש כאן שלוש דרכים, והדרך שאני ממליץ עליה לא
עולה כסף.

## דרך 1 (מומלצת): בלי שרת בכלל, קבצי מדינה מ-Geofabrik

OpenStreetMap מפורסמת גם כקבצים להורדה, מדינה-מדינה (Geofabrik, חינם, מתעדכן יומית).
במקום לשאול שרת, מורידים את קובץ המדינה, מסננים ממנו רק אטרקציות, ושואלים אותו מקומית.

| | |
|---|---|
| עלות | 0 |
| מגבלות קצב | אין |
| מה נדרש ממך | כלום. רץ מהמחשב שלי, צריך כ-20GB פנויים בדיסק בזמן הריצה |
| זמן | הורדה: פורטוגל 300MB, צרפת 4GB, גרמניה 4GB, ארה"ב 10GB. סינון: 5 עד 20 דקות למדינה. אחר כך כל עיר נבנית תוך שניות |
| איכות | זהה: אותם נתונים, אותן שאילתות |
| כיסוי | כל העולם, מדינה-מדינה |

זה שינוי בקוד הסקריפט (קורא קובץ במקום שרת), כיומיים עבודה שלי. אחריו, 330 הערים נבנות
בכמה שעות, וגם רענון חודשי הוא לילה אחד. **זו ההמלצה.**

## דרך 2: Overpass פרטי לאירופה בלבד (כ-20 יורו לחודש)

מתאים אם רוצים גם את הזמן-אמת (מסעדות ומקומות ערב סביב כל תחנה) מהיר ואמין לאירופה,
ולא רק את הבנייה המקדימה. דורש חשבון בספק ענן וכרטיס אשראי. התהליך, צעד-צעד:

1. **חשבון ב-Hetzner Cloud** (https://www.hetzner.com/cloud): הרשמה עם מייל, אימות זהות
   (לפעמים מבקשים צילום תעודה), כרטיס אשראי. אני לא יכול לעשות את זה במקומך.
2. **שרת:** Cloud → Add Server. מיקום: Falkenstein או Nuremberg. תמונה: Ubuntu 24.04.
   סוג: CPX41 (8 מעבדים, 16GB זיכרון, 240GB דיסק), כ-30 יורו לחודש. אם רוצים זול יותר:
   CX33 ועוד Volume של 200GB, כ-20 יורו. SSH key: לחיצה על "Add SSH key" והדבקה של מפתח
   שאני אכין לך. Create.
3. **ייבוא המפה:** אני מתחבר לשרת בפקודות שאכין, מתקין Docker ומריץ את התמונה
   `wiktorn/overpass-api` עם קובץ אירופה מ-Geofabrik (כ-28GB). הייבוא נמשך 12 עד 24 שעות
   ודורש כ-150GB בדיסק. עדכונים יומיים אוטומטיים.
4. **חיבור:** כתובת השרת נכנסת ל-Vercel כמשתנה `OVERPASS_URL`
   (Settings → Environment Variables), ולמחשב שלי לבנייה. מרגע זה גם האתר החי מביא
   מסעדות ומקומות ערב מהשרת שלנו, בלי התלות בשרתים הציבוריים.
5. **אבטחה:** חומת אש שמאפשרת גישה רק מכתובות Vercel ומהמחשב שלי, או סיסמה בסיסית
   בכתובת. אני מגדיר.

מגבלה כנה: רק אירופה. לאסיה ואמריקה צריך שרת שני או את דרך 1.

## דרך 3: Overpass פרטי לכל העולם (60 עד 120 דולר לחודש)

אותו תהליך עם שרת גדול בהרבה (למשל Hetzner CCX33 ועוד Volume של 600GB) וקובץ הכוכב
(כ-80GB). ייבוא של 2 עד 4 ימים. שווה רק אם יש אלפי משתמשים ביום שמבקשים מסעדות
בזמן-אמת בכל העולם. לא עכשיו.

## מה הקוד כבר יודע

- בזמן ריצה (`src/lib/providers/overpass.ts`): אם `OVERPASS_URL` מוגדר, הוא מנוסה ראשון.
  ב-Vercel, בלי משתנה כזה, Overpass לא מנוסה בכלל כי השרתים הציבוריים חוסמים ענן.
- בבנייה (`scripts/build-world.ts`): `OVERPASS_URL` מנוסה ראשון; עם `OVERPASS_ONLY=1`
  הוא היחיד, וההפסקות בין שאילתות יורדות מ-2 שניות ל-0.2.
